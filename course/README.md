# 用 qsm101 准备 QSM 课程

本系列为初学者提供一条从经济直觉到可运行模型的路线，也可用作 QSM 课程的课前准备和课后练习。先用 P01–P03 理解空间联系、因果识别和工具选择，再在 P04 中实际完成一次参数估计、基准校准与政策计算。

课程介绍中可以引用：[qsm101 仓库入口](../README.md) 和 [系列文章索引](../articles/INDEX.md)。读者无需一次掌握大型论文的全部机制，先跑通简单模型，再逐步加入通勤和更复杂的空间联系。

| 学习阶段 | 配套材料 | 完成后能做什么 |
|---|---|---|
| 建立直觉 | P01、P02 | 说明一个地区政策如何通过价格和人口影响其他地区 |
| 选择资料 | P03 | 根据自己的研究问题选择论文、课程讲义与工具包 |
| 第一次实现 | P04 | 区分数据、行为参数和反演基本面；核验一个两地区均衡 |
| 后续扩展 | 计划中的 P05 及新增推文 | 逐步研究通勤、居住与就业的关系 |

课程时间、授课安排、报名入口和费用以连享会正式公告为准。本页在正式课程页面确认后补入相应链接，不依据旧草稿发布安排。
