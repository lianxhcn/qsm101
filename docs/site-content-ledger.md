# QSM 基础网站内容与更新台账

记录日期：2026-10-05。用途：网站维护、课程更新和新增章节的共同编辑依据。

## 1. 网站定位

本站是**免费、完整、可动手的 QSM 入门在线讲义**。主要读者是第一次接触或初步接触 QSM 的研究生、青年教师，以及准备参加连享会 12 月课程的学员。只阅读网站，读者也应能理解地方冲击为何影响别处，找到可执行的学习路线，完成一个最小两地区模型的估计、校准、求解与核验，并带着这些知识阅读柏林墙研究。

网站同时承担课前预习和开课后随教学进度更新的功能。课程安排与报名信息始终以[课程主页](https://www.lianxh.cn/qsm.html)为准；首页、导航和页脚保留显要入口。作者、邮箱与许可集中在“关于本站”；只有独立下载后仍需辨认来源的 Notebook 在顶部保留作者和反向链接。

## 2. 内容尺度与编辑边界

网站把单篇推文改造成连续讲义，**不以压缩篇幅为目标**。原稿的经济直觉、模型设定、必要公式、图示、案例、学习资料、计算过程、结果解释、常见问题和参考文献原则上全部保留。可以删除的内容限于重复作者栏、推文检索入口、相关推文列表、跨章重复和已经由可执行代码完整替代的代码片段。

长页面可以使用右侧目录。不得为了追求页面短而把完整推导压成摘要，也不得为了保留字数而机械重复同一解释。验收标准是：每章能独立完成标题承诺的学习任务，相邻章节之间有自然承接。

## 4. Notebook 统一规范

两地区模型及后续扩展采用“章节网页与下载 Notebook 同源”的方式。一个 Notebook 同时承担以下任务：

1. 顶部说明背景、读者、先修要求和学习目标，并链接在线章节、网站首页、课程主页与仓库。
2. 每个 section 先解释本节要做什么，再给较小的可运行代码格，随后解释输出。
3. 数据优先读取本地固定文件，本地缺失时读取公开 GitHub raw 链接；同时给出可点击下载链接与输入校验值。
4. 模型设定、估计、校准、求解、图形、结果解释和核验连续呈现，不拆成理论页与计算页。
5. Notebook 从头执行并保留真实输出；下载文件不依赖参考脚本，不只堆代码和结果。
6. 结尾提供练习、答案脚手架、常见错误、模型边界和后续扩展。
7. 网页与下载文件由同一 ipynb 渲染，避免两份内容漂移。

后续通勤、贸易或其他模型章节均沿用上述规范，但要按各自模型重新定义数据、参数、校准、求解和核验，不能直接套用无通勤模型的数值。

## 5. 通勤扩展接口

通勤扩展固定放在两地区模型和柏林墙案例之间。正文、模型约定、固定数据、参数来源、程序、结果和核验材料全部完成后，再建立 site/pages/commuting.ipynb。完成前只在首页和侧边栏保留规划状态，不建空章节。

扩展必须明确居住地—工作地选择、通勤成本与流量、居民数与就业数，以及企业和住房市场分别使用哪个数量。可以继续研究 B 地住房增加 20%，但必须重新估计或校准并重新求解。随后若增加其他机制，也应插入最适合的教学位置，而不是按内部编号机械追加。

## 6. 每轮更新清单

1. 先更新“原稿小节—网页或 Notebook 单元”覆盖关系，确认没有把关键内容压成一句话或仅留外链。
2. 新内容优先补入现有章节；只有出现新的独立学习任务才增加主章节。
3. 每个数值标明教学设定、模拟估计、基准反演或政策计算的性质。基准拟合不等于外部验证，工人福利指数不等于政策净社会收益。
4. 改变模型或数据时，同步更新模型约定、输入、Notebook、参考结果、FAQ、更新记录和质量报告。
5. 从头执行 Notebook，检查固定输入校验值、参数估计、基准复原、零冲击、市场条件、解析解或其他独立性质。
6. 本地渲染后检查公式、代码输出、图片、目录、站内链接、下载链接、课程入口和 390 像素宽度下的阅读。
7. 公开页面不出现内部编号。代码采用 MIT，原创图文采用 CC BY 4.0；第三方材料保留各自许可与来源。
