# QSM 基础网站内容与更新台账

记录日期：2026-10-05。用途：下一轮网站改版和开课后更新的编辑依据。本台账记录目标与待办，不表示网页已经按此改完。

## 1. 网站定位

本站是**免费、完整、可动手的 QSM 入门在线讲义**。读者是首次接触或初步接触 QSM 的研究生、青年教师，以及准备参加连享会 12 月新课程的学员。读完网站，应能解释地方冲击如何传到别处，找到学习资料，完成一个最小两地区模型的设定、校准、求解与核验，并带着这些知识理解柏林墙研究。

网站既是课前预习材料，也是开课后按教学进度更新的公开讲义。它本身必须提供充分解释，不能只做课程宣传、文章摘要或原稿链接集。课程安排与报名信息以[课程主页](https://www.lianxh.cn/qsm.html)为准；首页、导航和页脚保留显要的返回入口。作者与许可集中写在“关于本站”，不必每页重复。

## 2. 内容尺度

主章节按“具体问题—经济直觉—变量与必要公式—图示或算例—结果含义与边界—下一步”展开。P01–P04 的关键推导、图、文献线索、计算过程、结果解释和实际使用提示应进入相应网页，不能压成几句摘要。也不逐段复制四篇推文、反复解释同一概念，或把完整论文复现的细节塞给首次阅读者。

验收标准是：只看网站主章节，读者便能完成该章的学习任务；查原稿、全部代码、固定数据与参考结果时再进入仓库。概念首次出现要解释；公式变量要有含义和单位；删掉后会使下一步计算无法理解的内容，不应只留下外链。

## 4. P05 接口

P05 是**两地区模型的进一步扩展**，固定放在“从校准到反事实”和“顶刊案例”之间。待正文、模型约定、数据和核验材料实际完成，再建立独立稳定的网页地址，建议为 site/pages/commuting.qmd，同时更新首页路径、导航、侧边栏、相邻章节链接、更新记录和必要的旧网址跳转。完成前仅保留规划说明，不建立空网页。

扩展须先定义居住地—工作地选择、通勤成本与流量、居民数和就业数，以及企业和住房市场各使用哪个数量。可以沿用 B 地住房增加 20% 的政策问题作对比，但 P04 的数值结果不能直接沿用。P05 需要自己的模型说明、输入、参数识别或校准方案、程序、结果和经济条件核验。课程进度决定何时上线，不改变它在阅读路径中的位置。

## 5. 后续更新和发布核对

1. 每轮先做“原稿小节—网页段落/图表”覆盖表，确认 P01 的直觉、P03 的学习材料、P04 的完整计算链与 P02 的顶刊案例都有实质讲解。页数服从学习任务，不为凑页数拆碎，也不因怕长而删去必要推导。
2. 开课后优先在相应章节补充例子、练习、图表和常见错误，再更新学习路线与更新记录；只有出现新的独立学习任务，才增主章节。课程主页链接保持显要，易变的报名信息仍由课程主页维护。
3. 标明教学样本、设定值、估计值、基准反演和政策计算的性质。基准拟合不等于外部验证；参考程序跑通不等于新会话独立实现通过。区分教学演示与真实研究、经验效应与结构参数、工人福利指数与净社会收益。
4. 新机制不得悄悄改写 P04。模型、数据或结果变化时，联动更新模型约定、运行说明、结果说明、网页和更新记录。P01–P03 原稿改写须另按作者指示。
5. 发布前检查公式变量、图表和文献来源、第三方素材许可、站内及课程链接、手机阅读、代码运行和经济条件。九张原配图可随仓库再分发；第三方图不纳入原创图文许可。代码 MIT、原创图文 CC BY 4.0 的说明集中维护。
