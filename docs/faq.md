# 常见理解问题

## P04 为什么没有通勤引力方程？

P04 让居住地与工作地相同，先演示校准和均衡求解。计划中的 P05 将允许跨地区通勤，分开居民数与就业数，引入通勤成本和居住地—工作地流量。新增机制需要重新校准和计算。

## 8000 条数据是哪个城市的调查？

它们是已知规则生成的模拟选择任务，用于检查估计程序能否恢复参数。两地区基准也是教学设定。文章提供真实研究的数据入口，但没有下载或估计真实城市样本。

## 校准后完全拟合基准，是否证明模型正确？

地区基本面由基准反演，匹配基准是这一步的要求。模型适用性还需要独立数据、识别策略或没有参与校准的结果验证。两行地区汇总数据不能识别 theta 与 beta。

## H 为什么不是住房套数？

H 表示同质住房服务的有效面积，由租金、工资总额和住房支出份额反演。这里没有独立观测实际建筑面积，不能把它当作真实城市住房套数。

## W 提高 1.88% 是每个人的收入都增加吗？

W 是模型工人在选择地区之前的福利指数。政策改变了可选地区的工资、租金和吸引力，并不意味着每个居民收入同幅提高；建设成本和区外所有者福利也未包含。

## 能运行参考代码，就说明 Codex 提示词已经测试过了吗？

还需要单独的新会话和固定输入。2026-10-05 的独立实现已实际运行：theta 与参考值相差约 $1.15\times10^{-9}$，政策下 B 地人口相差不到 0.000001 人；经济条件最大误差约 $2.99\times10^{-14}$。参考程序与独立实现是两份分别运行的证据。

## 出现“未找到中文字体”时怎么办？

本次参考程序复跑时确认：没有指定的中文字体，出图阶段会停止，数值 CSV 和 JSON 已在前面的步骤写出。先在运行命令末尾加 `--no-figures`，即可完成数值核验。需要重新出图时，再配置 Noto Sans CJK SC、Microsoft YaHei 或 SimHei；文章配图已经保存在 figures/ 中。

## 安装依赖时出现 GBK 解码错误怎么办？

2026-10-05 在 Windows、Python 3.11.14、pip 24.0 上实际出现 `UnicodeDecodeError`：pip 按 GBK 读取含中文注释的 UTF-8 依赖文件。改用以下命令后安装成功，`pip check` 和参考数值复跑均通过：

```text
python -X utf8 -m pip install -r articles/p04-minimal-qsm/requirements.txt
```

## Codex 在生成代码之前提示需要更新版本，是否算模型实现失败？

实际试跑时，Codex CLI 0.144.6 默认模型返回 HTTP 400 和版本兼容提示；显式指定 `gpt-6-sol` 又返回当前账号不支持。两轮均未开始实现。随后改用桌面版 Codex 的全新会话，原样提交提示词，程序运行和经济条件复测通过。若遇到同类报错，先核对本机 CLI 版本、所选模型与账号支持情况，再使用可用的 Codex 入口；不要把入口报错当作模型计算结果。

## Codex 读文件或运行命令时提示沙箱初始化失败怎么办？

本次桌面版新会话实际遇到 `windows sandbox: helper_unknown_error: setup refresh had errors`，默认命令无法启动。记录失败后，对当前独立目录的必要读写与运行使用授权执行方式，读入原始固定输入并完成程序复测。此问题发生在工具启动阶段；先确认命令尚未运行，再在当前工作目录内重试，并保留权限与错误记录。不要因参考程序能运行就跳过独立实现验收。
