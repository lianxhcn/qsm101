# 用 Codex 完成两种练习

## 先复现参考程序

按 [环境配置](setup.md) 运行 P04。核对 theta、反事实结果、verification.json 中的经济条件和版本。运行成功后，读懂居民选择、工资与住房出清分别在哪个函数实现。

## 再按提示词独立实现

在仓库外新建一个练习目录。只复制 P04 的 `prompts/model-input.md` 为 `model.md`、data/ 中的两个固定 CSV、requirements.txt，以及 `prompts/01-implement.txt`。不复制参考代码和参考输出。

在 Codex 中打开这个新目录，启动新会话，把实现提示词原样输入。提示词要求它读取固定样本、估计 theta、反演地区特征、复原基准，再计算 B 地区住房增加 20% 的均衡。首次实现完成后，再打开参考结果做对照。

保存初始提示词、输入校验值、软件环境、实际命令、补充说明和数值结果。如果改变了任务提示词，在另一个新目录、新会话中重新完整试跑。可以用 `prompts/02-verify.txt` 继续要求 Codex 核验经济条件。

## 怎么理解差异

如果模拟估计不一致，先检查是否使用同一份 CSV、alpha 是否给定、截距是否一起估计，以及优化器是否收敛。若基准正确而政策不同，检查是否只改变 H_B、是否在政策中错误地重新校准 B，以及是否同时重新求工资和租金。

这里列的是模型核对顺序。此次独立实现实际遇到的入口与沙箱问题及处理方法已写入 FAQ；参考与独立结果仍需分别检查。
