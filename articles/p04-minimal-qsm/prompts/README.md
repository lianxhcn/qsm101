# 提示词与独立实现输入

`01-implement.txt` 和 `02-verify.txt` 从 P04 正文的两个提示词代码块原样提取。本文修改提示词时，须同步这两个文件并在新会话中复测。

## 独立实现

在仓库外新建目录，复制 `model-input.md` 为 `model.md`，复制上级 data/ 中两个 CSV 和 requirements.txt。以新目录为 Codex 项目启动新会话，将 01-implement.txt 原样输入。首次实现完成前不提供参考程序和参考结果。

model-input.md 保留方程、数据规则与解析核验，省略参考估计值与政策答案。固定输入是已生成的 8000 条模拟任务，不重新随机抽样。

## 继续核验

独立实现实际运行后，可用 02-verify.txt 检查经济条件和共同冲击。保存真实输入、提示词、环境、命令和结果；需要补充说明时记录原因，再用修改后的最终提示词重新完整试跑。

参考程序与本地 Agent 的独立实现均已实际运行。原始提示词未修改；真实入口错误、沙箱问题及复测处理见正文第 6.3 节与 FAQ。
