# m1-baseline：随读 Agent 提示词

讲义练习使用给定材料；迁移任务需替换占位符。模板与填写示例分别使用，不要一起复制。先阅读[使用指南](usage-guide.md)。

## Agent · 讲义练习：先把经济设定对应到函数

**准备材料：** 下载并交给 Agent：[模型说明](../model.md)。

**适用条件：** 只讨论无通勤、总人口固定的两地区模型；居民与就业相同，不能套用到跨地区通勤情形。

**练习任务**

```text
我提供了无通勤两地区住房政策模型的设定与此任务所需的输入材料。
请先阅读 model.md，把无通勤两地区模型整理成方程与函数的对应说明。
逐项列出居民选择、工资、住房出清的输入、输出、单位和依赖关系。
解释为什么居住人口与就业人数相同，以及为什么一个人口比就足以表示未知量。
区分给定参数、需要估计的参数、反演基本面与均衡未知量。
先用自然语言写计算顺序和残差含义，不编程、不补设定、不填入政策答案。
遇到缺失条件请明确列出，不用默认假设替我决定。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 人口比怎样连到工资、房租与选择概率；政策情景内固定什么。

## Agent · 迁移到我的研究：把自己的模型整理成计算任务

**准备材料：** `{研究问题}`：用一两句话写要解释的现象；`{模型说明材料}`：已上传的文件名或粘贴的设定，尚不完整时说明缺口。

**适用条件：** 适用于准备实现的静态均衡模型；如果涉及动态决策、随机状态或多部门，应先补充相应设定，不能默认采用两地区算法。

**任务模板**

```text
我的研究问题是：{研究问题}。模型设定见：{模型说明材料}。
请先列出主体、选择、约束、市场条件和收入归属，暂不写代码。
将每个符号对应到含义、单位、数据来源或待确定条件。
区分外生给定量、需估计的参数、需反演的基本面与均衡未知量。
整理方程与函数的对应表，说明输入、输出、依赖顺序和残差的经济含义。
检查未知量、归一化及闭合条件是否齐全；方程数量相等本身不能证明可解或唯一。
缺失或冲突的假设单独列出，给出可讨论的选择，不自行替我决定。
交付设定摘要、计算步骤和待确认清单；这一轮只讨论模型。
```

**填写示例：** 以下是使用讲义材料的示范。先提供示例提到的材料，再单独复制；不要与上面的模板一起发送。

```text
我提供无通勤两地区住房政策模型的说明文件，想理解住房扩建怎样影响人口与价格。
请只整理设定与计算步骤，不编程。说明居民数为何等于就业数，并区分给定参数、校准基本面和人口份额未知量。
将住房出清、工资条件和居民选择对应到函数，列出缺失信息供我确认。
```

**拿到回复后看什么：** 是否说明了计算依赖、收入去向与缺失条件，是否把教材的未知量维度直接套到你的模型。

## Agent · 讲义练习：把完整设定实现为程序

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-choice-tasks.csv](../data/synthetic-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。

**适用条件：** 从零独立实现该无通勤特例。先创建新目录和新会话，仅提供模型与固定 CSV；首次实现结束前不提供参考程序或 Notebook。在本地项目中，将两个 CSV 放在 data/ 下，模型说明放在项目根目录；网页聊天可直接上传，并说明文件对应关系。

**练习任务**

```text
我提供了无通勤两地区住房政策模型的设定与此任务所需的输入材料。
请用 Python 实现一个两地区 QSM 教学模型。

输入：当前项目的 model.md、data/teaching-baseline.csv 和
data/synthetic-choice-tasks.csv。请先阅读，不读取其他参考实现。
Python 使用 numpy、scipy、pandas；新程序和结果分别写入 code/、results/。

模型约定：总劳动人口 N=100000，基准 A/B 人口为 60000/40000，
工资为 10000/8000 元/工人/月，租金为 100/80 元/平方米/月。
工人住在哪里就在哪里工作，只取得工资收入。普通商品价格为 1；
住房和固定生产要素由区外所有者持有，租金与非劳动要素收益不返还工人。
alpha=0.25，beta=0.90。地区吸引力 V_i=B_i*w_i/r_i**alpha。
居民份额 s_i=V_i**theta/sum(V_j**theta)，N_i=N*s_i。
生产 Y_i=Z_i*N_i**beta，工资 w_i=beta*Z_i*N_i**(beta-1)。
住房市场 r_i*H_i=alpha*w_i*N_i，H_i 在每个政策情景内固定。

固定选址样本为 8000 条模拟任务。令
x=ln_wage_ratio-alpha*ln_rent_ratio，
Pr(choose_B=1)=logistic(delta+theta*x)。同时估计 delta、theta，
保持 alpha 给定，theta 为正，检查极大似然收敛并计算 IID 信息矩阵标准误。
delta 只是任务截距，不能作为地区便利度代入均衡。禁止重新生成或替换输入。

请先说明每个函数对应的方程，然后编写并实际运行代码：
1. 读取固定样本并估计 theta；读取基准人口、工资和租金；
2. H_i=alpha*w_i0*N_i0/r_i0，Z_i=w_i0*N_i0**(1-beta)/beta；
   令 B_A=1，B_B=(N_B0/N_A0)**(1/theta)*(w_A0/w_B0)*(r_B0/r_A0)**alpha；
3. 用 x=log(N_B/N_A) 求居民选择的均衡残差，复原基准；
4. 只把 H_B 乘以 1.20，保留其他基本面和行为参数，求反事实均衡；
5. 计算 W=(sum(V_i**theta))**(1/theta)，报告变化及其福利口径；
6. theta 取 0.5 至 8，beta 取 0.8、0.9、1；每组参数先重新校准基准，
   再实施同一政策。敏感性曲线不作为置信区间；
7. 导出参数、基准与政策结果、敏感性表、核验 JSON 和运行命令。

验收：检查基准复原、零冲击、总人口、选择份额、住房出清和劳动边际产出。
本特例还有解析解：D=1+theta*(alpha+(1-alpha)*(1-beta))，
x1=x0+theta/D*(alpha*log(Hhat_B/Hhat_A)
              +(1-alpha)*log(Zhat_B/Zhat_A))。
各项相对误差或份额误差要求小于 1e-8；解析解与数值解也要对照。
模拟数据只检验程序，不能写成真实城市估计；基准拟合不能代替识别。
若缺少输入或遇到不一致，请说明具体原因，不调整参数来匹配预期结果。
```

**拿到回复后看什么：** 函数是否对应方程；是否实际运行并报告基准误差。不要只看代码生成完毕。

## Agent · 讲义练习：结果算出来后，检查经济条件

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-choice-tasks.csv](../data/synthetic-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。 实现或复查时另提供已有程序、校准结果和本次输出；可用[教学 Notebook](../downloads/baseline.ipynb)作参考。

**适用条件：** 核验已实现的无通勤特例，解析解及共同冲击性质依赖模型说明中的收入归属、固定人口和函数形式。

**练习任务**

```text
我提供了无通勤两地区住房政策模型的设定与此任务所需的输入材料。
请核验现有 QSM 程序，不改变模型设定。
逐项检查：人口总量、居民选择概率、工资等于劳动边际产出、住房出清。
验证零冲击返回基准，并把数值结果与本模型的解析解对照。
把两个地区住房同时增加 20%，检查人口份额和工资是否保持不变，
两地租金是否同除以 1.20，工人福利指数是否同乘以 1.20**alpha。
指出哪些结果由设定直接决定，哪些仍需要真实数据验证。
再把两个地区生产率同时乘以 1.10，检查人口份额是否不变、工资与租金
是否同乘以 1.10、福利指数是否同乘以 1.10**(1-alpha)。
保存实际运行命令、输入校验值、环境版本和残差。
发现不一致时定位方程或代码，不要通过调整参数消除差异。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 每项条件的误差与阈值，以及失败项的具体原因。

## Agent · 迁移到我的研究：为自己的程序设计核验清单

**准备材料：** `{模型说明材料}`：完整方程、变量口径与归一化；`{程序与运行输出}`：脚本和本次结果或报错；`{误差标准}`：已有尺度与阈值，未确定时填请先提出建议及理由。

**适用条件：** 适用于已有实现的模型。对称性、共同冲击不变性和解析解只在模型满足相应条件时使用。

**任务模板**

```text
请依据 {模型说明材料} 独立复核 {程序与运行输出}。
误差标准是：{误差标准}。先说明各条件采用绝对误差、相对误差还是份额误差。
从最终输出重算守恒关系、行为方程与市场条件，不只读取求解器成功标志或程序自带检查。
列出零冲击、标签互换、特殊极限与多个初值中哪些检验适用，解释理论预期；不适用的项目说明原因。
若模型存在已知解析解，再进行数值与解析解对照；不要为完成清单而编造解析解。
实际运行可执行的检查，逐项输出误差、阈值和通过状态，保留失败项。
没有运行环境或材料不全时说明缺口，不把拟执行步骤写成已通过。
不通过调参、替换输入或放宽阈值隐藏错误；数值检验不作为一般唯一性证明。
```

**填写示例：** 以下是使用讲义材料的示范。先提供示例提到的材料，再单独复制；不要与上面的模板一起发送。

```text
我提供无通勤两地区住房政策模型、程序和本次输出。按模型说明规定的相对误差或份额误差 1e-8 进行核验。
请重算居民选择、工资和住房出清，检查零冲击，并与该特例给出的解析解比较。
共同住房冲击的检验必须说明不变性依赖的假设；保留误差与运行记录，不修改参数迎合答案。
```

**拿到回复后看什么：** 检查是否由最终结果重算，阈值是否与单位和尺度匹配，特殊检验是否有理论依据。

## Agent · 讲义练习：把住房扩建改成 10%

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-choice-tasks.csv](../data/synthetic-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。 实现或复查时另提供已有程序、校准结果和本次输出；可用[教学 Notebook](../downloads/baseline.ipynb)作参考。

**适用条件：** 只改变 B 地住房扩建力度，保留无通勤模型机制和原基准。

**练习任务**

```text
我提供了无通勤两地区住房政策模型的设定与此任务所需的输入材料。
请阅读所提供无通勤模型的 model.md 和已有程序，只把 B 地区住房扩建幅度从 20% 改为 10%。
保持原基准、行为参数、生产率、便利度及 A 地区住房不变；不要按政策结果重新校准。
先指出需要修改的政策参数与相关输出，再修改并实际运行。
分别报告固定价格预测与一般均衡下的 B 人口、工资、租金和工人事前福利变化。
复查基准、零冲击、人口守恒和市场残差，保留原 20% 情景作对照。
结果写入新目录，不覆盖原结果，也不按预期方向调参。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 是否只改了住房倍率；新结果与旧结果是否来自同一基准。
