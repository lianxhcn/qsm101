# 怎样使用 Agent 提示词？

<div class="page-intro">

提示词帮助你把研究问题、模型条件和检查要求交代清楚。你可以先用讲义提供的材料完成练习，再把相同的任务方法迁移到自己的研究；每一步都要判断设定是否适用、程序是否实际运行，以及结果是否满足经济条件。

</div>

## 1. 选择当前需要的任务

浅紫色的**讲义练习**使用教材给定的模型和数据，适合核对公式、实现算法或调整政策力度。卡片提供材料链接；先下载并交给 Agent，再复制任务。讲义中的数字和特殊检验只在相应设定下成立。

浅蓝色的**迁移到我的研究**提供带 `{……}` 的模板。把括号及其中内容一起替换为自己的材料或设想，再发送给 Agent。填写示例单独列出，帮助理解怎样填写；不要把示例中的参数和结论原样当成自己的设定。颜色与左侧图标表示用途不同，不表示难度或重要程度。

卡片随阅读过程出现：理解设定时整理方程，进入计算时实现算法，得到结果后核验经济条件。无需一次复制整章提示词。

讲义练习左侧使用书本标记，迁移任务使用向外箭头；右侧的小箭头只表示展开或收起。你可以按当前需要选择其中一类，不必把相邻两张卡片当作连续步骤。

## 2. 按任务准备材料

通常需要交代研究问题、模型说明、数据口径、已有程序与结果，以及本次任务。只提供当前步骤所需的材料；没有的部分明确写无或待确定。

- **研究问题：** 想解释什么现象，比较什么政策或机制。例如，住房扩建是否同时改变居民与就业的分布。
- **模型说明：** 主体如何选择，受到什么约束，哪些市场需要出清，参数含义与单位是什么，以及收入归谁所有。
- **数据口径：** 文件和变量含义、观测单位，以及哪些量来自观测、模拟、给定参数或模型反演。
- **程序与结果：** 当前完成到哪一步，提供有关脚本、报错或输出。只有研究想法时，可以先不提供程序。
- **本次任务：** 说明希望交付设定讨论、代码、计算结果还是核验报告，并约定如何判断完成。

本站的 `model.md` 是模型说明文件，文件名本身没有特殊作用。自己的材料可以是 Markdown、Word、论文相关段落或直接粘贴的文字。提供论文时指出要使用哪些设定，不假定 Agent 会自动采用你心里想的版本。

新会话需要重新提供相关材料。网页中的下载链接方便你取得材料，不能保证 Agent 已打开链接或读过页面。在本地 Agent 中明确可读取的文件；在网页聊天中上传附件或粘贴必要内容。

## 3. 填写、检查，再发送

1. **Step 1**: 展开卡片，检查适用条件和材料清单。只有两地区模型才可直接使用两地区求解或解析解。
2. **Step 2**: 迁移任务中逐项替换 `{模型说明材料}`、`{政策变化}` 等占位符。文件名应与实际上传的材料一致；若有重名文件，先给材料加上明确标识。
3. **Step 3**: 单独复制任务模板。先让 Agent 说明理解到的条件、缺少的材料和准备改动的方程，再按任务要求进入计算。
4. **Step 4**: 用卡片的检查要点核对回复。要求区分已运行的结果与尚未执行的建议，并保留失败项。

只有一个想法时，可以先向 Agent 说明研究问题，请它列出主体、选择、约束和待确定条件。这一步形成的是讨论稿，不能让它替你编造数据、识别依据或政策结论。

## 4. 分清三种实践方式

**阅读与核对代码。** 使用已执行的 Notebook，检查每个函数对应哪条方程、每个输出回答什么问题。程序能运行与经济含义正确仍需分别检查。

**从零独立实现。** 在新目录、新会话中提供模型、固定输入和任务书，首次实现结束前不提供参考程序、Notebook 或政策答案。选择仅含输入的练习包；完整离线包含参考材料，不能把它整个交给独立实现的 Agent。

**修改已有程序。** 可以提供现有代码和输出，无需假装从零开始。先明确变化影响哪些条件，再修改、运行和核验。调整政策力度通常可保留既有基准；增加迁移、通勤或内生住房供给等机制时，可能需要重写方程、补充数据和重新校准。

## 5. 判断哪些内容可以迁移

整理方程与函数的对应关系、列明固定量、保存残差等做法可用于多种模型。两维未知量、解析解、对称性检验、特定福利公式和校准顺序依赖模型条件。迁移时先核对这些条件，不只更换文件名或参数值。

改变行为参数后的敏感性分析，需要说明哪些基准观测保持不变、哪些基本面重新反演；同一组政策反事实中又有哪些量固定。不同教学模型可能采用不同规则，不能直接混用。

拟合基准不等于识别。通过零冲击、市场出清和多个初值检查，也不能证明所有设定下解唯一或政策在现实中有效。模型设定、识别策略与结果解释仍需要研究者判断。

## 6. 从哪里开始练习

先在 [M1：无通勤基准模型](https://lianxhcn.github.io/qsm101/site/pages/m1-baseline.html) 学习把设定对应到函数，再在 [M2：加入跨地区通勤](https://lianxhcn.github.io/qsm101/site/pages/m2-commuting.html) 区分居民与就业，随后在 [M3：通勤成本变化](https://lianxhcn.github.io/qsm101/site/pages/m3-transport-policy.html) 比较固定价格与均衡结果。每章页尾提供随读提示词下载；完整离线练习包内的 `prompts/usage-guide.md` 保留本指南。
