# m2-commuting：随读 Agent 提示词

讲义练习使用给定材料；迁移任务需替换占位符。模板与填写示例分别使用，不要一起复制。先阅读[使用指南](usage-guide.md)。

## Agent · 讲义练习：怎样把 无通勤模型 扩展为允许通勤

**准备材料：** 下载并交给 Agent：[模型说明](../model.md)。 另提供[无通勤模型说明](../models/no-commuting-model.md)；上传时保留文件名，以区分两套设定。

**适用条件：** 从无通勤两地区设定扩展为居住与工作联合选择。比较机制时要另行控制基准差异。

**练习任务**

```text
我提供了允许跨地区通勤的两地区住房政策模型的设定与此任务所需的输入材料。
我希望把居住地等于工作地的无通勤两地区模型扩展为通勤两地区住房政策模型的居住与工作联合选择。
请对照两份模型说明，先给出需要保留、新增和修改的对象，暂不写代码。
说明 M 的行是居住地、列是工作地，R 是行和，E 是列和；工资用工作地 E 计算。
把住房支出改为居住地工人在各工作地工资的加总，不用本地工资乘居民数替代。
明确四种选择、通勤效用损失与预算约束的关系，列出新增的市场一致性检查。
通勤两地区住房政策模型使用自己的对称教学基准；不要沿用无通勤两地区模型的基准数值并把结果差异当作通勤效应。
说明数据还缺什么，待模型说明一致后再实现。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 是否真正区分了居民与就业，以及哪些方程随通勤机制改变。

## Agent · 讲义练习：把模拟估计与基准校准分开

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-joint-choice-tasks.csv](../data/synthetic-joint-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。 实现或复查时另提供已有程序、校准结果和本次输出；可用[教学 Notebook](../downloads/commuting.ipynb)作参考。

**适用条件：** 四选项模拟估计与对称教学基准反演采用不同输入；主政策使用约定的教学参数。

**练习任务**

```text
我提供了允许跨地区通勤的两地区住房政策模型的设定与此任务所需的输入材料。
请按所提供的模型说明文件检查参数估计与基准反演，分别报告两部分。
模拟估计使用固定四选项样本，每个选择任务恰有一项 chosen=1。
固定 alpha，估计 theta 与 kappa，使用连续的 commute_multiplier；报告 tau=kappa/theta。
检查可识别秩、得分和优化状态；计算 IID 标准误，Delta 法保留两个系数的协方差。
主政策仍使用教学真值，不自动代入这次模拟估计值。
给定基准 OD 和价格，按住房出清反演 H、按工资边际产出反演 Z，并核对四格流量与行列合计。
不要重新生成样本、混用参数来源，或把匹配基准称为真实数据识别。
实际运行后给出参数来源表、估计诊断和逐项基准误差。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 教学真值、模拟估计值和反演基本面是否分开；OD 是否得到复原。

## Agent · 迁移到我的研究：区分估计、给定参数与基准反演

**准备材料：** `{模型说明材料}`：模型方程与归一化；`{数据及变量说明}`：文件、单位和观测/模拟来源；`{参数来源说明}`：已有估计、文献取值或教学给定值，缺项标明未定。

**适用条件：** 用于正式编码前整理参数来源。估计方法、标准误和校准目标应由模型与数据决定；不默认采用某一套模拟选择模型。

**任务模板**

```text
请结合 {模型说明材料}、{数据及变量说明} 和 {参数来源说明}，整理参数与基准构造计划。
分别列出可观测量、外部给定参数、拟估计参数和需反演的基本面，不混用来源。
对拟估计参数说明识别来自哪些变化、需要什么假设，哪些问题仅凭现有数据无法确认。
根据抽样与误差结构提出推断方法；不要默认独立同分布或把模拟样本当作真实观测。
列出基准拟合目标、归一化、反演顺序和拟合误差检查。
明确反事实使用哪组行为参数，以及改变参数后哪些观测固定、哪些量重新校准。
先交付参数来源表、识别与数据缺口、计算计划，不生成新数据或虚构估计结果。
```

**填写示例：** 以下是使用讲义材料的示范。先提供示例提到的材料，再单独复制；不要与上面的模板一起发送。

```text
我提供通勤两地区模型说明、四选项模拟选择数据、对称教学基准和参数约定。
请把模拟估计 theta、kappa 与给定参数下反演 H、Z 分开列示。主政策按教学参数运行，暂不代入模拟估计值。
说明模拟结果只能检验程序，以及基准拟合不能代替真实数据识别；这一轮只制定计划。
```

**拿到回复后看什么：** 是否把基准拟合误写成识别，是否说明了政策计算最终使用的参数及其来源。

## Agent · 讲义练习：让 Agent 实现两维均衡算法

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-joint-choice-tasks.csv](../data/synthetic-joint-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。 实现或复查时另提供已有程序、校准结果和本次输出；可用[教学 Notebook](../downloads/commuting.ipynb)作参考。

**适用条件：** 两地区联合选择模型，以居民和就业两个对数比求解；增加地区后需重新确定未知量与残差。

**练习任务**

```text
我提供了允许跨地区通勤的两地区住房政策模型的设定与此任务所需的输入材料。
请按所提供的通勤模型说明文件实现并运行均衡求解器，先解释函数与方程的对应。
用 log(R_B/R_A) 与 log(E_B/E_A) 表示候选居民和就业份额。
由候选就业计算工资，再根据条件工作地概率计算各居住地平均工资与候选租金。
用联合选择概率重算四格 M，构造居民和就业边际与候选值之差。
先复原所提供模型的对称基准；用最终联合流量重新检查住房出清与工资条件。
尝试 model.md 指定的多个初值，保留求解器状态、最终残差与失败记录。
更换算法时仍求解同一组方程，不改参数、不放宽阈值。
输出函数说明、基准结果、实际运行命令和经济条件误差。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 两个残差各代表什么；检查是否使用最终联合流量，而非只验证中间候选租金。

## Agent · 讲义练习：比较有通勤与无通勤的住房政策

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-joint-choice-tasks.csv](../data/synthetic-joint-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。 实现或复查时另提供已有程序、校准结果和本次输出；可用[教学 Notebook](../downloads/commuting.ipynb)作参考。

**适用条件：** 在同一对称教学起点内比较允许通勤和仅本地工作的住房政策，各自校准并相对各自基准计算福利变化。

**练习任务**

```text
我提供了允许跨地区通勤的两地区住房政策模型的设定与此任务所需的输入材料。
请在通勤两地区住房政策模型的同一对称教学基准内，比较允许通勤与仅本地工作的住房政策。
两套模型各自按 model.md 校准，不直接调用无通勤两地区模型的政策结果。
分别只把 H_B 乘以 1.20，固定该组其他基本面、总人口和行为参数。
实际求解后并列报告居民、就业、工资、租金及四格通勤流量，保留完整计算精度。
福利增幅均相对于各自基准，不把选择集合不同的福利水平直接相减。
检查人口守恒、市场出清和受限模型的跨区流量为零；不硬编码答案。
用居住地住房需求与工作地劳动投入解释差异，不只复述表中数字。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 比较是否基于本章共同起点；居民变化与就业变化是否分别解释。

## Agent · 讲义练习：让检查回到经济方程

**准备材料：** 下载并交给 Agent：[模型说明](../model.md) · [synthetic-joint-choice-tasks.csv](../data/synthetic-joint-choice-tasks.csv) · [teaching-baseline.csv](../data/teaching-baseline.csv)。 实现或复查时另提供已有程序、校准结果和本次输出；可用[教学 Notebook](../downloads/commuting.ipynb)作参考。

**适用条件：** 给定模型函数形式下的经济与数值检查；特殊极限不自动推广到其他选择或成本设定。

**练习任务**

```text
我提供了允许跨地区通勤的两地区住房政策模型的设定与此任务所需的输入材料。
请依据所提供的通勤模型说明文件重新运行并检查当前程序，不只调用其自带验证函数。
由最终 M 复算行和 R、列和 E、总工人数、联合选择概率、工资与住房市场条件。
检查零冲击、共同住房与生产率冲击、地区标签互换及多个初值。
核对高通勤成本接近本地工作限制、零通勤成本下概率可分离等特殊情形。
逐项导出误差、阈值和通过状态；保留所有失败项。
若失败，先定位方程、索引、单位或算法问题，不通过调参、换样本或放宽阈值消除差异。
区分本次重新计算的证据与引用的参考结果。
若材料缺失，请列明缺口；需要运行却无法运行时，区分拟执行步骤与已完成结果。
```

**拿到回复后看什么：** 经济条件是否逐项满足；特殊情形为何应有这些性质。

## Agent · 迁移到我的研究：增加一个机制前，明确要改什么

**准备材料：** `{研究问题}`：具体问题；`{新增机制}`：这次只讨论的一项机制；`{模型说明材料}`：现有设定与关键方程；`{已有程序}`：文件或目录，无实现时填无。

**适用条件：** 用于机制扩展的讨论阶段。新增通勤、迁移、供给弹性或拥堵可能改变闭合条件与识别需求，不等同于调整政策力度。

**任务模板**

```text
我的研究问题是：{研究问题}；拟增加的机制是：{新增机制}。
现有设定见 {模型说明材料}，已有实现为 {已有程序}。
请列出该机制会影响的选择、约束、生产、收入归属或市场条件。
区分必须修改的方程、新参数、可用数据与仍缺失的识别依据，不自动加入其他机制。
说明原基准、归一化和原有核验哪些仍适用，哪些需要重建。
提出一个最小可计算例子，用于隔离新机制，并说明它不能证明什么。
这一轮只交付设定修改清单、数据缺口和验证计划，不编程、不虚构数据或参数。
待关键条件确定后，再按修改方程、实现、运行、核验的顺序推进。
```

**填写示例：** 以下是使用讲义材料的示范。先提供示例提到的材料，再单独复制；不要与上面的模板一起发送。

```text
我想研究居住地与工作地分离如何改变住房政策的传导，拟在无通勤两地区模型中加入跨地区通勤。
我提供原模型说明、原程序和候选的居住/工作联合选择设定。
请先讨论新增流量、住房支出的收入汇总、数据需要和闭合条件，不写代码；不要把两个不同基准下的数值差异直接解释为通勤效应。
```

**拿到回复后看什么：** 新增机制是否落实到方程、数据与闭合条件，是否说明原有检验为何能继续使用。
