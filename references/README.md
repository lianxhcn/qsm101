# 文献、数据与软件入口

每篇文章的参考文献是对应主题的完整列表。P03 还整理了综述、工具包和专题论文，建议先从它的 [文献与工具入口](../articles/p03-learning-roadmap/article.md) 开始。

P04 的模型是本项目构造的教学特例，没有复现下列论文，也没有读取下列真实调查数据。

| 对象 | 官方或学术入口 | 用途 |
|---|---|---|
| Redding (2023) | [JEP 论文](https://doi.org/10.1257/jep.37.2.75) | 城市定量模型的理论与数据联系 |
| Davis & Ortalo-Magné (2011) | [论文](https://doi.org/10.1016/j.red.2009.12.003) | 住房支出、工资与租金 |
| ACS PUMS | [美国 Census 数据说明](https://www.census.gov/programs-surveys/acs/microdata.html) | 个人与住房微观数据入口 |
| CFPS | [北京大学数据申请](https://www.isss.pku.edu.cn/cfps/sjzx/index.htm) | 国内住户微观调查入口，按年份核查变量与权限 |
| Codex AGENTS.md | [OpenAI 官方说明](https://developers.openai.com/codex/guides/agents-md) | 项目长期协作规则 |

P04 的 alpha=0.25 与 beta=0.90 是教学设定，theta 来自模拟样本。请结合实际研究对象核查文献适用性、数据单位、覆盖范围和识别依据。
